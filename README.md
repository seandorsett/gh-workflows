# GitHub workflows

This repository contains a daily agentic documentation-sync workflow and a small
example CLI for exercising documentation maintenance.

## Greeting CLI

Requires Python 3 and uses only the standard library. Run commands from the
repository root.

```shell
python src/greet.py
```

Prints `Hello, World!`. Use `--name` to customize the greeting:

```shell
python src/greet.py --name Ada
```

Prints `Hello, Ada!`. Use `python src/greet.py --help` for usage information.
